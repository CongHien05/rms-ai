# Chapter 5 — AI trong Thiết kế & Kiến trúc Phần mềm

## 1. Mục tiêu theo đề cương

Sử dụng AI để hỗ trợ Architecture Design, Architecture Patterns, System
Modeling/UML, Database Design, API Design và Design Patterns; mọi đề xuất vẫn
phải được nhóm kiểm tra với yêu cầu sản phẩm.

## 2. RMS-AI áp dụng chương này như thế nào

RMS-AI đã mô tả ranh giới Frontend, Backend, AI service, dữ liệu khái niệm, API
ban đầu và nền tảng database. Các tài liệu này có trước cấu trúc tracking Chapter
5 nên tiếp tục được giữ tại Chapter 3 và chỉ được liên kết từ đây.

## 5. Bằng chứng AI-assisted workflow

Các artifact liên kết có quy ước trạng thái, phần tự rà soát, câu hỏi `TBD` và
lịch sử Git cho từng đợt bổ sung rồi merge. Chưa tập trung bằng chứng vào chapter
này.

## 6. Việc tiếp theo

Rà soát các quyết định kiến trúc với implementation hiện tại, bổ sung UML và
pattern evidence khi phạm vi tương ứng được nhóm phê duyệt.
