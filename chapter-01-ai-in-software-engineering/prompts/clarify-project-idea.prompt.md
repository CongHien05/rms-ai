# Prompt: Clarify RMS-AI Project Idea

## Objective

Clarify the RMS-AI project idea by analyzing the problem, users, product value, AI opportunities, scope risks, and unresolved questions before implementation begins.

## Prompt

Analyze the RMS-AI project idea as an AI-assisted decision-support system for software project resource management.

Focus on:

- the core problem the product should solve
- target users and their responsibilities
- user pain points related to project risk, skills, bench time, overload, and allocation decisions
- proposed product value
- candidate AI capabilities that may support decision-making
- scope risks that could make the project too broad
- unresolved questions that should be clarified before detailed design

Keep the output concise and suitable for an early university project. Clearly separate confirmed direction from future ideas or undecided details.

Do not design database schemas.
Do not design APIs.
Do not choose final ML algorithms.
Do not create implementation architecture.
